# CRUD-Python
Sistema de gerenciamento de vendas desenvolvido em Python com integração ao MySQL. O projeto foi criado com o objetivo de aplicar conceitos de programação, funções, manipulação de dados e integração com banco de dados.

A aplicação implementa as quatro operações fundamentais de um CRUD:

- **Create:** cadastro de novos produtos;
- **Read:** consulta e listagem dos produtos;
- **Update:** atualização do valor dos produtos;
- **Delete:** exclusão de produtos pelo ID.

O sistema possui um menu interativo executado pelo terminal e utiliza o MySQL Connector/Python para realizar a comunicação entre a aplicação e o banco de dados.
